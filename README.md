# yorii.media — Portfolio of Youssef Boukhari (YoRii)

Static single-page portfolio. Cinematic-editorial design, zero build step.

- `index.html` — the entire site (HTML/CSS/JS inline)
- `hero.jpg` / `story.jpg` — portraits
- `logos/` — client logo wall
- `netlify.toml` — deploy config (publish root)

Deploys automatically on push via Netlify.
